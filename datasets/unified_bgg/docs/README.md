# 示例报告

这里仅保留当前统一数据集生成的可复用示例，不存放阶段计划、临时评测输出或旧版本报告。

## 示例集合

- `top100_reports/`：100 个高评分游戏的统一资料报告。
- `top10_reports_v4/`：按实际游玩流程组织的最新 Top 10 报告。
- `party_top10/`：派对游戏筛选与报告示例。
- `two_player_top10/`：双人游戏筛选与报告示例。
- `brass_birmingham_flow_report_v2.md`：单个游戏的流程化分析示例。
- `brass_birmingham_full_report.md`：单个游戏的完整资料型示例。

报告中的事实应结合 BGG ID、`snapshot_date`、来源文件和 Hugging Face 清单使用。规则书、评论和其他来源文本可能受版权或平台条款限制，仅用于研究、检索和桌游设计分析。

数据 schema、构建审计和维护者内部记录不再放在公开示例目录；使用者请从仓库根目录的 `Readme.md` 开始，直接下载预构建索引并调用 Skill。
