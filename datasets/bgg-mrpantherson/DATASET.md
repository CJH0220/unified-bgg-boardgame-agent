## 0. 它唯一的、但很重要的价值

数据本身很普通（Top-5000、20 列、2017–2018 的老快照），但它是本地**唯一一份
同一 schema、同一口径、三个时间点**的数据 —— 这让一个别处无法回答的问题变得可测：

> **同一批游戏的评分会随时间怎么变？跨快照混用评分会引入多大偏差？**

## 3. ⭐ 实测：评分漂移（2017-04 → 2018-06，共 14 个月）

两个快照共有 **4,547** 款游戏（452 款跌出 Top-5000，另有 452 款新进入 —— **14 个月换血率 9%**）。

对这 4,547 款共有游戏：

| 指标 | 均值变化 | 中位变化 | p5 | p95 |
|---|---|---|---|---|
| `avg_rating`（算术均分） | **−0.0294** | −0.0156 | −0.140 | +0.035 |
| `geek_rating`（贝叶斯分） | **−0.0027** | −0.0216 | −0.054 | +0.093 |
| `rank`（正 = 名次上升） | −166.1 | −190.0 | −536 | +260 |

### 三条可直接用于建模决策的结论

1. **算术均分系统性下滑**：同一批游戏 14 个月内平均掉 0.029 分，中位掉 0.016，p5 掉 0.14。
   机制是「早期评分者是核心爱好者，后期涌入的休闲玩家给分更低」。
   → **跨快照混用 `avg_rating` 会引入时间偏差**：老游戏的分被更多后来者稀释过，新游戏还没被稀释。

2. **贝叶斯分几乎不动**（均值 −0.003，是算术均分漂移量的 1/11）。
   → 这是「排序目标要用 `bayesaverage` 而不是 `average`」在时间维度上的实证依据，
   不只是因为它对小样本更稳，也因为它**对时间更稳**。

3. **名次普遍下滑**（中位 −190）：存量游戏被新游戏持续挤下去。
   → 用 `rank` 做跨年份标签时必须做**同期归一化**（如换成分位数），否则模型学到的是「发行年份」。

```python
import pandas as pd
ENC = {"bgg_db_2017_04.csv": "cp1252", "bgg_db_2018_01.csv": "cp1252", "bgg_db_1806.csv": "utf-8-sig"}
snaps = {f.split("_")[-1].replace(".csv",""): pd.read_csv(f"raw/{f}", encoding=e) for f, e in ENC.items()}
a, b = snaps["04"], snaps["1806"]
m = a.merge(b, on="game_id", suffixes=("_2017", "_2018"))
m["drift"] = m["avg_rating_2018"] - m["avg_rating_2017"]
```

## 4. 局限

- **Top-5000 截断样本**，与 mattadamhouser 一样有 range restriction 问题，不能估计总体
- 快照最新只到 2018-06，机制词表停留在 52 个（见 `../bgg-gabrio/DATASET.md` §4 的词表演化表）
- 三个快照间隔不均（14 个月内 3 个点），做时序建模的时间分辨率有限
