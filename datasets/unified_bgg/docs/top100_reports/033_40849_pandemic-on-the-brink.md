## 3. 核心机制亮点（1~3个关键）

### 1. Hand Management（手牌管理）
- 机制定位：把手牌当作行动权限和节奏资源来使用，而不是单纯的出牌池。
- 评价：这类设计好玩的地方在于：你不是想做什么就能做什么，而是要先看牌是否允许你在正确的位置、用正确的方式做事。
- 解析：在本作中，每次行动都要弃牌，地点牌、产业牌和万能牌还分别决定你能跨网络建造、指定产业建造或临时绕过限制，因此手牌本身就是一张“行动地图”。
- 规则锚点：
  - On the Brink includes new event cards, new role cards, rules for five players, and optional game challenges to increase the difficulty of the Pandemic base game.

### 2. Trading（交易）
- 机制定位：把玩家之间的交换、讨价还价和信息博弈变成玩法核心。
- 评价：这种机制最强的地方是让桌面互动真正变成可操作的资源。
- 解析：评论若经常提到“deal”“trade”“table talk”，说明互动就是这作的魅力。

### 3. Set Collection（套组收集）
- 机制定位：Set Collection 会把本作的决策重心放在这条系统线上。
- 评价：它未必是最直观的卖点，但通常会影响整局游戏的节奏、风险和收益分布。
- 解析：评论若反复围绕这项机制讨论，说明它是本作体验的关键结构之一。

## 4. 游戏简介与说明

Pandemic: On the Brink includes new event cards, new role cards, rules for five players, and optional game challenges to increase the difficulty of the Pandemic base game. These new challenges, which can be used individually or combined for even more difficult play, are as follows: The Virulent Strain challenge makes one disease become particularly deadly in unpredictable ways. The Mutation challenge adds a fifth (purple) disease that behaves differently than the original four. The Bio-Terrorist challenge pits one player against the others!
